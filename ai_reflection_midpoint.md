Our project uses Logistic Regression to study diabetes predictions in the Pima Indians Diabetes dataset. I worked on checking the data and creating Phase I visualizations to understand where the model made mistakes.

GenAI helped me write notebook code, fix errors, and understand the charts. I had to check its suggestions: a download link did not work, the code had an undefined variable, and zero values could make some charts misleading. I learned to test the code and check the results instead of accepting the first answer.

Our test set had 154 records. At the default threshold, the model missed 27 positive cases. The charts also showed that changing the threshold changes the balance between missed cases and false alarms. These results describe only our test set, so we should not treat them as medical advice or apply them to everyone.
